欢迎开启 Git 学习之旅！Git 是目前世界上最先进的分布式版本控制系统，也是程序员和创作者的必备技能。别被“分布式”、“版本控制”这些词吓到，它的核心其实就是帮你安全地管理文件历史和高效地多人协作。
这份教程将带你从零基础到上手，我们分四个阶段来攻克它：
🚀 第一阶段：核心概念与准备
在敲命令之前，先理解 Git 的“世界观”，这比死记硬背命令更重要。
1. Git 的三大工作区域
你可以把 Git 想象成一个有严格流程的物流仓库：
表格
区域	作用	类比
工作区 (Working Directory)	你当前正在编辑、看到的文件	你的办公桌
暂存区 (Stage/Index)	准备提交的“购物车”，可以挑选要提交哪些修改	购物车
本地仓库 (Repository)	提交后的永久历史记录，存在 .git 隐藏文件夹里	仓库货架
💡 核心流程： 工作区 git add ➡️ 暂存区 git commit ➡️ 本地仓库
2. 初次配置（只需一次）
Git 需要知道“你是谁”，才能记录是谁做的修改。
bash

编辑



git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
🛠️ 第二阶段：掌握“三板斧”
这是你日常 90% 场景都会用到的命令，也是单人开发的核心。
1. 创建/获取仓库
本地新建： git init （在当前文件夹初始化）
远程克隆： git clone <仓库地址> （把别人的项目完整下载到本地）
2. 提交修改（日常循环）
bash

编辑



# 1. 查看状态（随时用，养成好习惯！）
git status 

# 2. 放入暂存区（. 代表当前所有修改）
git add . 

# 3. 提交到本地仓库（-m 后面写清楚你做了什么）
git commit -m "修复了登录页面的按钮样式"
3. 推送到远程
bash

编辑



# 将本地仓库的提交推送到 GitHub/GitLab 等远程服务器
git push 
🌿 第三阶段：分支管理（Git 的灵魂）
分支是 Git 最强大的功能。你可以把它理解为“平行宇宙”：在主线任务（main/master）之外，开辟一条支线去尝试新功能或修复 Bug，成功后再合并回来，互不干扰。
常用分支命令
bash

编辑



# 查看当前分支
git branch

# 创建并切换到新分支（最常用！）
git checkout -b feature/login-page 
# 或者新版命令：git switch -c feature/login-page

# 切换回主分支
git checkout main

# 将功能分支合并到当前分支
git merge feature/login-page

# 删除已合并的分支
git branch -d feature/login-page
⚠️ 避坑指南： 切换分支前，确保工作区干净（已提交或已暂存），否则 Git 会阻止你切换，防止修改丢失。
🔄 第四阶段：撤销与回退（后悔药）
Git 最大的安全感在于：几乎任何操作都可以撤销。
表格
场景	命令	说明
改错了，想放弃修改	git restore <file>	让文件回到上次提交的样子（工作区）
add 错了，想撤回暂存	git restore --staged <file>	文件还在，只是从购物车拿出来了
commit 错了，想改信息	git commit --amend	修改最后一次提交的说明或内容
想回到过去的版本	git log 查看历史，git checkout <commit-id>	查看历史快照（注意：这是“查看”，不是“回退”）
📚 推荐学习资源
光看教程是不够的，Git 必须动手练。
交互式练习（强烈推荐）：
Learn Git Branching：一个可视化的网页游戏，通过拖拽和命令直观理解分支、合并、变基。这是新手入门的神器！
Oh My Git!：开源的 Git 游戏，像玩卡牌游戏一样学 Git。
权威书籍：
《Pro Git》：Git 官方推荐书籍，中文版免费且质量极高。遇到不懂的概念，直接查这本书。
日常工具：
VS Code / IntelliJ IDEA：现在的 IDE 内置了非常强大的 Git 图形界面。建议先用命令行理解原理，再用图形界面提高效率。
